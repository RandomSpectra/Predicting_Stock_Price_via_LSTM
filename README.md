# Stock Price Prediction Using LSTM and Statistical Models

**Erdős Institute Data Science Boot Camp — Summer 2024**

**Team:** Deven Gill, Ajay Aryan, and Dionel Jaime

This repository highlights a collaborative capstone project completed during the Erdős Institute's Data Science Boot Camp.

We investigated one-day-ahead stock price forecasting using LSTM neural networks, sliding-window linear regression, and a naïve forecasting baseline.

Our models were evaluated using four-fold time-series cross-validation and mean squared error (MSE). In our experiments, the naïve forecasting method outperformed the more complex models.
